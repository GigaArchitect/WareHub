# WareHub 🛠️

**WareHub is a desktop application that allows users to create and manage their own warehouses.**

## Features 🧾

- Create and manage warehouses
- Add and track vehicle expenses
- Convert Arabic numerals to Western numerals
- Database integration for storing and retrieving data

## Technologies Used 🤖

- Java
- JavaFX
- SQL
- Maven

## Getting Started

### Prerequisites ☕

- Java Development Kit (JDK) 23 or higher
- Maven

### Installation ⚒️

1. Clone the repository:
    ```sh
    git clone https://github.com/GigaArchitect/WareHub.git
    cd WareHub
    ```

2. Build the project using Maven:
    ```sh
    mvn clean install
    ```

### Running the Application

1. Run the application using Maven:
    ```sh
    mvn javafx:run
    ```
